# Student Task Manager

A simple web-based task management application built using HTML, CSS, and JavaScript.

## Features
- Add and delete tasks
- Track daily activities
- Data stored using browser local storage
- Clean and user-friendly interface

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Use
1. Open the application in browser
2. Add tasks using input field
3. Manage tasks easily
